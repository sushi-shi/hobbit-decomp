# Hobbit decompilation

C++ reconstruction of **The Hobbit (2003)**, PC no-CD v1.3 (`Meridian.exe`),
built with the pinned Visual C++ 6.0 toolchain under Wine. Retail bytes decide
correctness; hashes are in [config/retail/targets.json](config/retail/targets.json).
Tooling and source ownership follow local Gruntz and HoMM1. Xbox symbols and
sibling Entropy source provide evidence, checked against the PC executable.
Supply your own matching executable and game data. Original binaries, maps,
media payloads and their download links are excluded from this repository.
See [reference binaries](docs/reference-binaries.md) for full hashes and setup.

The score below is the last verified cohort19 bank. Cohort20 source is integrated;
its strict target generation currently needs the UI counter at PC RVA `0x413040`.
See the [integration checkpoint](config/evidence/cohort20-integration-checkpoint.json).

## Quickstart

With Nix flakes enabled, run from the repository root:

```sh
HOBBIT_SKIP_INIT=1 nix develop .#build
hobbit init --exe /path/to/Meridian.exe
hobbit inspect
hobbit build
hobbit match x_files_x_plus
hobbit verify status
hobbit sema disasm 0x247b00
```

Initialization verifies and stages your input in ignored `build/orig/`;
omit `--exe` on subsequent runs. `nix develop .#build --command hobbit build`
runs a single command. `bin/hobbit-shell` is also available when editing
untracked environment files. Compiler binaries, extracted media, Wine state,
analysis and comparison artifacts stay in ignored `build/`.
The matching workflow does not launch a game.

## Versions

The current reconstruction targets PC no-CD v1.3. The recovered Xbox
`default.xbe` and original `default.map` are symbol and source-ownership
references, not alternative PC address maps. Other historical builds are
listed in [executable research](docs/02-executables-and-toolchains.md); their
old measurements are not fresh verification of restored inputs.

`hobbit clean --verify` exports and compiles standalone reconstructed source.
A complete new game executable still requires the remaining source and an
evidence-backed link profile. Unknown regions and uncovered vtables remain
visible in the verification results.
